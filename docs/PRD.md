# PRD - 할 일 관리 앱

## 1. Why - 목적
- 할 일을 1년 목표와 연결해 관리
- 일일 실행이 주간 계획 → 1년 목표 달성으로 이어지는 구조 제공
- 할 일 완료 시 주간 진행률 자동 반영
- 상태(todo/doing/done)를 직관적으로 파악하고 드래그 앤 드롭으로 변경

## 2. Who - 타깃 사용자
- 장기 목표를 세우고 일/주 단위로 실행하려는 개인 사용자
- 할 일의 진행 상태를 시각적으로 관리하고 싶은 사용자
- 일일 할 일과 상위 목표의 연결이 필요한 사용자

## 3. User Flow
- 1년 목표 생성 → 주간계획 생성 및 목표 연결 → 일일 할 일 생성 및 주간계획 연결
- 할 일 상태 변경 (todo → doing → done)
  - 드래그 앤 드롭으로 컬럼 간 이동
- 상태 변경 시 주간 진행률 자동 갱신
- 할 일 / 주간계획 / 1년 목표 수정
- 삭제
  - 하위 항목이 없는 경우에만 삭제
  - 하위 항목이 있으면 삭제 차단 및 안내
- 일일 / 주간 / 1년 목표 단위로 조회

## 4. 기능 요구 사항

### P0 - 핵심 기능
- **1년 목표 CRUD**
  - 생성: 제목, 연도 입력
  - 조회: 목표 목록 및 연결된 주간계획 표시
  - 수정: 제목, 연도 변경
  - 삭제: 연결된 주간계획이 없을 때만 가능
- **주간계획 CRUD**
  - 생성: 제목, 기간(시작일·종료일) 입력 및 1년 목표 연결 (필수)
  - 조회: 주간계획 목록, 연결된 할 일, 주간 진행률 표시
  - 수정: 제목, 기간, 연결된 1년 목표 변경
  - 삭제: 연결된 할 일이 없을 때만 가능
- **할 일 CRUD**
  - 생성: 제목, 날짜(일일) 입력 및 주간계획 연결 (필수)
  - 조회: 등록된 할 일과 현재 상태 표시
  - 수정: 할 일 정보 및 연결된 주간계획 변경
  - 삭제: 할 일 삭제 및 목록에서 제거
- **상태 관리**
  - 상태값: `todo`, `doing`, `done`
  - 할 일당 현재 상태 1개 유지
  - 상태 변경 후 목록과 저장 데이터에 결과 반영
- **드래그 앤 드롭**
  - 상태별 영역 간 할 일 카드 이동 지원
  - 카드 이동 완료 시 이동한 영역의 상태로 변경
  - 상태 변경 시 주간 진행률 갱신
- **기간 구조**
  - 일일: 할 일 관리 (할 일의 날짜 속성 기준)
  - 주간: 주간계획 관리 (주간계획의 시작일·종료일 기준)
  - 연간: 1년 목표 관리 (목표의 연도 기준)
- **구조 연결**
  - `할 일 → 주간계획 → 1년 목표` 관계 유지
  - 할 일은 반드시 하나의 주간계획에 연결
  - 주간계획은 반드시 하나의 1년 목표에 연결
  - 할 일에서 소속 주간계획 식별 가능
  - 주간계획에서 연결된 1년 목표 식별 가능
  - 1년 목표에서 연결된 주간계획 식별 가능
- **주간 진행률 자동 반영**
  - 주간계획에 연결된 할 일 중 `done` 상태인 항목을 완료 항목으로 집계
  - 주간 진행률 = (`done` 할 일 수 / 연결된 전체 할 일 수) × 100
  - 연결된 할 일이 0개면 진행률 `0%` 표시
  - 할 일 생성·삭제·주간계획 연결 변경·상태 변경 시 즉시 재계산
- **기간별 조회**
  - 일일: 날짜 기준 할 일 조회
  - 주간: 주간계획 기준 할 일 및 진행률 조회
  - 1년: 1년 목표 기준 주간계획 조회
- **검증 기준**
  - 1년 목표·주간계획·할 일의 생성·조회·수정·삭제 결과가 목록에 반영된다.
  - 하위 항목이 있는 주간계획·1년 목표는 삭제되지 않는다.
  - 주간계획 없이 할 일을, 1년 목표 없이 주간계획을 생성할 수 없다.
  - 드래그 앤 드롭으로 이동한 카드의 상태가 올바르게 변경된다.
  - 할 일과 주간계획, 주간계획과 1년 목표의 연결 관계를 확인할 수 있다.
  - 동일 주간계획의 할 일 완료 상태가 바뀌면 진행률이 재계산된다.

### P1 - 추가 기능
- 1년 목표 진행률 자동 반영 (주간 진행률 기반)
